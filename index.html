A note before the details

I build web applications and stay with them after they ship. Most of my work is React and Vue.js in TypeScript on top of Node.js services and REST APIs, in enterprise systems that also run on C#, .NET and Java, with PostgreSQL, SQL Server and Azure underneath.

At Bell Canada I led the Data Connectors Dashboard, an internal platform tool used across the organization by hundreds of people. I owned the solution design, the interface, the services behind it, the code review and the support that followed.

I release through GitLab CI/CD into Docker and Kubernetes with Argo CD, and I put Grafana on what I build so the next decision rests on evidence.

I also created FinanceCanada.ca, a live personal-finance platform for Canadians, and built it end to end in Next.js and TypeScript on a Sanity headless CMS.

Away from the keyboard I ran the Mohawk College chess club, which is why this page thinks a few moves ahead.

React, Node.js, Stripe, Twilio, Google Maps Platform

Anti-Phishing Browser Plugin

A client and server security tool that inspects pages and warns people about suspected phishing sites in real time. Detection is split between a lightweight in-browser client and a server-side service, so the extension stays responsive while the heavier checks are centralized.

JavaScript, browser extension, Node.js
